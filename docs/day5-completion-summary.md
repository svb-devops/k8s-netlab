## 📚 技术总结

### 实验7核心知识

**PV/PVC/StorageClass三层抽象:**
```
StorageClass → 定义存储类型
PersistentVolume → 实际存储资源
PersistentVolumeClaim → 存储请求
Pod → 通过PVC使用存储
```

**K3s特点:**
- 默认local-path-provisioner
- 动态PV供应
- WaitForFirstConsumer模式

**关键验证:**
- 数据持久化效果 ✅
- Pod删除后数据保留 ✅
- ReclaimPolicy工作机制 ✅

### 实验8核心知识

**ConfigMap vs Secret:**

| 特性 | ConfigMap | Secret |
|------|-----------|--------|
| 用途 | 非敏感配置 | 敏感信息 |
| 存储 | 明文 | Base64编码 |
| 热更新 | Volume挂载支持 | Volume挂载支持 |

**注入方式对比:**
- 环境变量: 简单，不会自动更新
- Volume挂载: 热更新，更安全（推荐）

**关键验证:**
- ConfigMap多种创建方式 ✅
- Secret Base64编码解码 ✅
- 两种注入方式对比 ✅
