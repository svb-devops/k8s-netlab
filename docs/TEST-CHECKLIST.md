# K8S NetLab v1.0 功能测试清单

**发布前必须全部通过**
运行自动化脚本：`bash scripts/test-release.sh`
手动测试项在下方标注 [手动]

---

## 1. 后端 API

### 1.1 基础端点
- [ ] `GET /`          → 返回 index.html (200)
- [ ] `GET /login.html` → 返回登录页 (200)
- [ ] `GET /api`       → 返回版本信息 (200)
- [ ] `GET /api/health` → `{"status":"healthy"}` (200)

### 1.2 实验文档 API
- [ ] `GET /api/experiments` → 返回 11 个实验列表
- [ ] 列表包含字段: id, title, difficulty, duration, phase
- [ ] `GET /api/experiments/01` → 返回实验内容 (200)
- [ ] `GET /api/experiments/11` → 返回实验内容 (200)
- [ ] `GET /api/experiments/99` → 返回 404
- [ ] 内容字段包含: id, title, difficulty, duration, content

### 1.3 静态文件
- [ ] `GET /js/api.js`      → 200
- [ ] `GET /js/app.js`      → 200
- [ ] `GET /js/docs.js`     → 200
- [ ] `GET /js/terminal.js` → 200
- [ ] `GET /js/auth.js`     → 200

### 1.4 VM 管理 API（需要 Proxmox 连接）
- [ ] `GET /api/vms`       → 返回 VM 列表
- [ ] `POST /api/vms/create` → 创建成功（返回 vm_id）
- [ ] `GET /api/vms/{id}/status` → 返回 VM 状态
- [ ] `DELETE /api/vms/{id}` → 删除成功

## 3. 实验文档面板 [手动]

### 3.1 基础功能（第一期）
- [ ] 打开终端连接后，左侧出现实验选择下拉框
- [ ] 下拉框包含全部 11 个实验
- [ ] 选择实验 → 显示 loading → 加载文档
- [ ] 文档区渲染正常: 标题、段落、列表
- [ ] Info Bar 显示难度星级和预计时长
- [ ] 代码块：语法高亮（深色背景）
- [ ] 代码块：右上角有"复制"按钮
- [ ] 点击"复制" → 代码进入剪贴板 → 按钮变"已复制 ✓"（2秒后恢复）
- [ ] 切换实验 → 文档更新，滚动回顶部

### 3.2 步骤导航（第二期）
- [ ] 选择有步骤的实验（实验 01-11 均有 6-10 步）
- [ ] 文档加载后，info bar 下方出现步骤导航区
- [ ] 导航区显示: "实验步骤" 标签 + "X/Y 完成" + 进度条
- [ ] 步骤胶囊按钮数量与实验步骤数一致:
  - 实验01: 7个 | 实验02: 9个 | 实验03: 10个
  - 实验04: 10个 | 实验05: 7个 | 实验06: 7个
  - 实验07: 8个 | 实验08: 8个 | 实验09: 7个
  - 实验10: 6个 | 实验11: 7个
- [ ] 点击步骤胶囊 → 文档平滑滚动到对应位置
- [ ] 点击后该胶囊变蓝（活跃状态）
- [ ] 滚动文档 → 当前可见步骤对应的胶囊自动高亮

### 3.3 进度追踪（第二期）
- [ ] 胶囊内有复选框（小方框）
- [ ] 点击复选框 → 胶囊变绿，复选框打勾
- [ ] 进度条宽度增加，文字更新（如 "1/7 完成"）
- [ ] 再次点击已完成步骤的复选框 → 取消完成，恢复灰色
- [ ] 刷新页面，重新选择同一实验 → 已完成步骤保持勾选状态
- [ ] 切换到另一个实验 → 该实验有自己独立的进度
- [ ] 切回原实验 → 原进度仍然保留
