# K8S NetLab 实验指南

欢迎来到 Kubernetes 网络学习实验平台！本指南包含 **11 个精心设计的实验**，帮助你从零开始掌握 Kubernetes 网络原理和实践。

---

## 📋 实验列表

### 🟢 基础级 (Foundation)

#### 实验 1: Pod 网络基础与容器通信
- **难度**: ⭐⭐
- **时间**: 30 分钟
- **内容**: 理解 Pod 网络模型、容器间通信、Pause 容器、veth pair、IP 分配机制
- **目标**: 掌握 Pod 内部网络架构和容器间通信原理
- **状态**: 📝 待创建

#### 实验 2: Service ClusterIP 工作原理
- **难度**: ⭐⭐
- **时间**: 35 分钟
- **内容**: ClusterIP 服务创建、kube-proxy 工作模式、iptables 规则分析、负载均衡机制
- **目标**: 深入理解 Service 的实现原理和流量转发机制
- **状态**: 📝 待创建

#### 实验 3: Service NodePort 与外部访问
- **难度**: ⭐⭐⭐
- **时间**: 30 分钟
- **内容**: NodePort 服务配置、端口映射、外部访问路径、SNAT/DNAT 规则
- **目标**: 掌握从集群外部访问服务的方法
- **状态**: 📝 待创建

---

### 🟡 进阶级 (Intermediate)

#### 实验 4: Calico 网络策略与隔离
- **难度**: ⭐⭐⭐
- **时间**: 40 分钟
- **内容**: NetworkPolicy 创建、Ingress/Egress 规则、命名空间隔离、标签选择器
- **目标**: 实现细粒度的网络访问控制
- **状态**: 📝 待创建

#### 实验 5: Kubernetes DNS 解析机制
- **难度**: ⭐⭐⭐

- **内容**: CoreDNS 配置、服务发现、FQDN 解析、DNS 策略、ndots 参数
- **目标**: 理解 K8s 内部 DNS 工作原理和服务发现机制
- **状态**: 📝 待创建

#### 实验 6: Ingress 控制器与 HTTP 路由
- **难度**: ⭐⭐⭐⭐
- **时间**: 45 分钟
- **内容**: NGINX Ingress 部署、路由规则配置、虚拟主机、TLS 终止、路径重写
- **目标**: 掌握 7 层负载均衡和 HTTP 流量管理
- **状态**: 📝 待创建

#### 实验 7: LoadBalancer 与 MetalLB
- **难度**: ⭐⭐⭐⭐
- **时间**: 40 分钟
- **内容**: MetalLB 部署、地址池配置、L2/BGP 模式、LoadBalancer 服务创建
- **目标**: 在裸金属环境实现 LoadBalancer 服务
- **状态**: 📝 待创建

## 🛠️ 实验环境准备

### 方式 1: 使用 K8S NetLab 平台 (推荐)

1. 访问 K8S NetLab 网页界面
2. 注册/登录账号
3. 点击"创建实验环境"按钮

5. 点击"终端"按钮进入 SSH 终端
6. 开始实验！

**优势**:
- ✅ 无需本地安装
- ✅ 环境一致性保证
- ✅ 自动清理，无需维护
- ✅ 随时随地访问

### 方式 2: 本地搭建

**系统要求**:
- CPU: 4核以上
- 内存: 8GB 以上
- 磁盘: 40GB 可用空间
- 操作系统: Ubuntu 22.04 / Debian 11+

**安装步骤**:
```bash
# 克隆项目
git clone https://github.com/your-org/k8s-netlab.git
cd k8s-netlab

# 运行安装脚本
./scripts/install.sh

# 验证安装
kubectl get nodes
```

## 💪 实验技巧

### 高效学习建议

1. **按顺序完成**: 实验有递进关系，建议按序学习
2. **动手实践**: 不要只看不做，必须亲自操作
3. **做好笔记**: 记录关键命令和遇到的问题
4. **理解原理**: 不要死记命令，理解背后原理
5. **多做实验**: 完成扩展练习巩固知识

### 常见错误避免

- ❌ 跳过基础实验直接做高级实验
- ❌ 只复制粘贴命令，不理解含义
- ❌ 遇到问题就重启，不查找根本原因
- ❌ 不做验证步骤就继续下一步

### 调试建议

```bash
# 常用调试命令速查
kubectl get pods -o wide              # 查看 Pod 详情
kubectl describe pod <pod-name>       # 查看 Pod 事件
kubectl logs <pod-name>               # 查看 Pod 日志
kubectl exec -it <pod> -- /bin/sh     # 进入 Pod 调试

# 网络调试
kubectl get svc                       # 查看服务
kubectl get endpoints                 # 查看端点
kubectl get networkpolicies           # 查看网络策略
```
