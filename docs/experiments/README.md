# K8S NetLab 实验指南

欢迎来到 Kubernetes 网络学习实验平台！本指南包含 **11 个实验**，覆盖从网络基础到综合实战的完整学习路径。

---

## 实验列表

### Phase 1 — 网络基础

#### 实验 1: Kubernetes 网络模型基础验证
- **难度**: ⭐⭐（入门）
- **时长**: 30–35 分钟
- **前置**: 已有可用的 K8s 集群
- **内容**: 验证 Pod IP 分配机制、测试 Pod 间直接通信、观察 Pod 网络命名空间，理解 IP-per-Pod 模型和三大网络基本要求

#### 实验 2: Pod 网络实现原理深入探索
- **难度**: ⭐⭐⭐（中级）
- **时长**: 35–40 分钟
- **前置**: 完成实验 1
- **内容**: 观察 CNI 插件工作流程、veth pair 创建过程、Linux 网桥作用，追踪数据包在 Pod 间的底层转发路径

#### 实验 3: Service 负载均衡机制
- **难度**: ⭐⭐⭐（中级）
- **时长**: 35–40 分钟
- **前置**: 完成实验 1、2
- **内容**: 理解 ClusterIP / NodePort / LoadBalancer 三种 Service 类型，分析 kube-proxy iptables 规则，验证负载均衡效果和 Endpoint 动态更新

---

### Phase 2 — 流量控制

#### 实验 4: Ingress 控制器详解
- **难度**: ⭐⭐⭐⭐（中高级）
- **时长**: 45–50 分钟
- **前置**: 完成实验 1–3
- **内容**: 理解 Ingress 工作原理，配置基于路径和主机名的路由规则，掌握 K3s 内置 Traefik 的基本使用

#### 实验 5: NetworkPolicy 网络策略
- **难度**: ⭐⭐⭐（中级）
- **时长**: 35–40 分钟
- **前置**: 完成实验 1–3
- **内容**: 实现 Pod 级别网络隔离，配置 Ingress/Egress 规则，理解基于标签选择器的流量控制和网络安全最佳实践

#### 实验 6: DNS 服务发现
- **难度**: ⭐⭐⭐（中级）
- **时长**: 35–40 分钟
- **前置**: 完成实验 3
- **内容**: 掌握 Service DNS 记录格式和解析、跨命名空间 DNS 访问、Headless Service DNS 特性，学习常用 DNS 调试技巧

---

### Phase 3 — 配置与存储

#### 实验 7: 持久化存储 PV/PVC/StorageClass
- **难度**: ⭐⭐⭐（中级）
- **时长**: 40–45 分钟
- **前置**: 完成实验 1–3
- **内容**: 理解 Kubernetes 三层存储抽象（PV / PVC / StorageClass），使用 K3s local-path-provisioner 实现动态供应，验证 Pod 删除后数据持久化

#### 实验 8: ConfigMap 和 Secret 配置管理
- **难度**: ⭐⭐⭐（中级）
- **时长**: 35–40 分钟
- **前置**: 完成实验 1–3
- **内容**: 实践配置与代码分离原则，掌握 ConfigMap / Secret 的创建和使用，学习环境变量注入和 Volume 挂载两种方式，理解配置热更新机制

---

### Phase 4 — 有状态应用与运维

#### 实验 9: StatefulSet 有状态应用管理
- **难度**: ⭐⭐⭐⭐（中高级）
- **时长**: 45–50 分钟
- **前置**: 完成实验 6、7
- **内容**: 理解 StatefulSet 与 Deployment 的本质区别，掌握稳定网络标识、独立持久存储、有序部署三大特性，配置 Headless Service

#### 实验 10: 监控和日志管理
- **难度**: ⭐⭐⭐（中级）
- **时长**: 35–40 分钟
- **前置**: 完成实验 1–3
- **内容**: 掌握 `kubectl logs` 各种用法（多容器、历史日志），部署 metrics-server，使用 `kubectl top` 查看节点和 Pod 资源使用

---

### Phase 5 — 综合实战

#### 实验 11: 综合实战 — 部署完整三层 Web 应用
- **难度**: ⭐⭐⭐⭐（中高级）
- **时长**: 50–60 分钟
- **前置**: 完成实验 1–10
- **内容**: 综合运用全部知识，部署前端 + 后端 API + 数据库三层应用，实践 Namespace 隔离、ConfigMap/Secret 配置管理、Ingress 统一路由、有状态数据库生产级部署、滚动更新与故障排查

## 常用调试命令

```bash
kubectl get pods -o wide              # 查看 Pod 详情（含 IP 和节点）
kubectl describe pod <pod-name>       # 查看 Pod 事件和状态
kubectl logs <pod-name> -c <container> # 查看容器日志
kubectl exec -it <pod> -- /bin/sh     # 进入容器调试

kubectl get svc                       # 查看 Service
kubectl get endpoints                 # 查看 Endpoint
kubectl get networkpolicies           # 查看网络策略
kubectl top pods                      # 查看 Pod 资源使用
```
